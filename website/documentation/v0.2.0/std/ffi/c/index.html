std::ffi::c (v0.2.0)

Type aliases, constants, and C ABI signatures used by standard wrappers.

Archived

Overview

std::ffi::c contains the raw C bindings used by the standard library. The declarations are grouped by area, such as I/O, memory, math, and primitive C types.

Most application code should prefer std::io, std::mem, or std::math. Those modules use clearer Thrust names while still relying on the same C symbols underneath.

Use the raw FFI layer when you need a C symbol directly or when writing a wrapper for a library that is not yet covered by std.

Source: thrustc/std/v0.2.0/ffi/c/*.thrust

Behavior and Use

Each declaration must match the external C symbol. Pay special attention to pointer types, return types, and variadic functions.

Keep raw extern calls in small wrappers when possible. That makes mistakes easier to find and keeps the rest of the program cleaner.

Examples

import std::ffi::c::io as c;

fn printLine(msg: CString) void @public {
    c::puts(msg);
}
import std::ffi::c::math as c;

fn absValue(v: f64) f64 @public {
    return c::fabs(v);
}

Notes

  • Raw bindings follow the behavior of the C library on the target platform.
  • Prefer wrapper modules for normal application code.
  • When a C library changes, recheck the matching Thrust declarations.
